# NEXORA OS

Un escritorio web experimental hecho con HTML, CSS y JavaScript.

## Cómo probarlo
1. Descarga los tres archivos `index.html`, `style.css` y `app.js`.
2. Déjalos juntos en la misma carpeta.
3. Abre `index.html` en un navegador.

## Publicarlo con GitHub y Vercel
1. Crea un repositorio nuevo en GitHub, por ejemplo `nexora-os`.
2. Sube `index.html`, `style.css` y `app.js` a la raíz del repositorio (no dentro de otra carpeta).
3. En Vercel elige **Add New → Project** y conecta ese repositorio.
4. Deja los ajustes predeterminados y pulsa **Deploy**.
5. Abre la URL que te dé Vercel.

## Incluye
- Escritorio adaptable a móvil y ordenador.
- Ventanas que se pueden mover, minimizar, maximizar y cerrar.
- Lanzador de aplicaciones.
- Notas guardadas en el navegador.
- Calculadora.
- Terminal simulada con comandos básicos.
- Ajustes de color y brillo.

Nota: esto es un escritorio web, no un sistema operativo de arranque ni un reemplazo de Windows/ChromeOS.
